**Subject: Before Tuesday — "Build It, Show It" workshop (what to expect + 15-min setup)**

Hi everyone,

A quick note before our session on **[Tue June 30, 6:00–8:30pm @ Edmonton Unlimited]**.

**What this is:** a hands-on working session, not a lecture. You'll take one idea
and turn it into something a stranger can actually *click* — a working demo you

**You'll leave with:**
- A repeatable process — problem → spec → opportunity → build → test — you can rerun anytime

**Please set up before you arrive (~15 min):**
1. Laptop + charger
2. Your idea (+ any discovery notes)
3. A **GitHub** account — github.com
4. **VS Code** installed — code.visualstudio.com
5. **Claude Code** installed — *a Claude **Pro** plan is **highly recommended**

6. A free **Lovable** account — lovable.dev (free tier ≈5 credits/day; optional —

**Tools we'll use:** GitHub (your code lives here) · VS Code (your editor) ·
Claude Code (your AI build partner) · Lovable (for the no-code path).

**Two paths — pick what fits you:**
- **No-code (Lovable):** describe your screen in a few prompts → a clickable app.
  Uses Lovable's free credits.
- **Level-up (Claude Code + starter kit):** build a real app (React + API +
  database) you fully own — no Lovable needed.

Both end in a demo. **Using the free Lovable credits is totally optional** — you
can lean on them or skip them.

**Already using Codex or another AI coding tool?** You're welcome — the *process*

follow along tap-for-tap we recommend Claude Code. On Codex you'd paste the same
stage prompts by hand (I'll share them) and get the same result — just without the
one-tap commands.

Come with an idea and a willingness to ship something rough. See you Tuesday!
