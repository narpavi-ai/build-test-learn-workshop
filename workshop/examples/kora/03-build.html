Design pass

  • Hero states the value in one line: "Ask your budget anything" above the input, not just the logo.
  • Colour restraint — the warm amber accent used only on the safe-to-spend number and the primary button; everything else neutral.
  • Loading state — "Kora is thinking…" while the answer streams in, instead of a frozen screen.
  • Empty state on the transaction list before the first question is asked.
  • Mobile squint test passed at 375px — the answer card and grid both reflow cleanly.

No new packages needed for this build — shadcn's Card, Badge, and Skeleton covered the answer panel and loading state.
