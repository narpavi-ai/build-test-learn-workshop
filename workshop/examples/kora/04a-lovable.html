Route A — Build in Lovable (no-code)

3–4 prompts → a clickable Kora

The hands-on route. Paste these into Lovable one at a time, free-tier friendly.

Inputs · what you told the AI

  • App name & tagline?
    Kora — "Ask your budget anything."
  • Brand vibe & colour?
    Warm and friendly; a warm amber.
  • Anything about the look that matters?
    One big "safe to spend" number up top; a calm chat box.

Outputs · the prompt script

Prompt 1 · Scaffold the screen
Build a single-page app called Kora. Top: a heading "Kora" with the tagline "Ask your budget anything." Below it, a large highlighted card showing "Safe to spend this week: $147". Under that, a chat-style text input with placeholder "Can we afford dinner out this weekend?" and an amber "Ask Kora" button. Warm, friendly style, warm-amber accent (#D97706), off-white background.

Should produce: the screen with the big number + chat box. If it breaks: re-prompt with "just the layout, no logic yet."

Prompt 2 · Add believable fake data + answers
Add ~20 hard-coded transactions for a couple's month (rent $1,850, groceries ×4, Netflix/Spotify/Amazon subscriptions, dining ×3, gas, utilities, gym, coffee ×4, two paydays of $3,100). When I type a question and click Ask Kora, show a 2–3 sentence answer based on the data — e.g. "groceries" → total spent on groceries; "afford dinner" → yes/no vs safe-to-spend. Below the answer, show the transactions as a list with red expenses and green income.

Should produce: a question returns a grounded answer + the list. If it breaks: "answer from the hard-coded totals; don't call any API."

Prompt 3 · Detail view
When I click a transaction, open a detail view showing the description, amount, category and date, with a "← Back" button.

Should produce: click a row → detail → back. If it breaks: "use a simple modal instead of routing."

Prompt 4 · Polish
Polish Kora: warm-amber primary, rounded cards with soft shadows, the safe-to-spend number large and confident, a friendly empty hint ("Ask Kora anything ↑"), and a "Kora is thinking…" loading state. Make it look finished.

Should produce: a demo-ready look. If it breaks: stop here — a working demo beats a pretty broken one.

Free tier is ~5 credits/day, so 3–4 prompts. Don't debug in circles — re-prompt clearly. Next: /6-test-iterate, then publish to a URL.
