Stage 5 — Build (into the starter template)

Kora is running

One screen, real round-trip, AI answers — no API key needed for the demo.

Inputs · build decisions

  • Resource name
    transactions (renamed from items)
  • Fields
    id, date, description, amount (REAL — negative = expense, positive = income), category
  • AI approach
    Smart-fake: reads the real SQLite data, routes the question by keyword, returns a plain-English answer + safe-to-spend number. Swap for a Claude API call at the REAL-DATA HOOK.

Working endpoints

  • GET /api/health → {"ok":true}
  • GET /api/items → ~20 transactions
  • GET /api/ask?q=can we afford dinner out → {"answer":"Yes…","safeToSpend":814}

Real-data hook — upgrade path

The generateAnswer() function in apps/api/src/items.js is the one place to swap for a real Claude API call later. Add ANTHROPIC_API_KEY to .env, install @anthropic-ai/sdk, replace the function body — the route and the whole front-end stay the same.
