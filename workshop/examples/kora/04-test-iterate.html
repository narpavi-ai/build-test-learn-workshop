Stage 4 — Test & Iterate (Build → Test → Learn)

Make it work, then make it shareable

Walk the exact demo path, fix or bounce back to Build, ship a link, then write down what you learned.

Inputs · the demo path & what broke

  • The path the audience will click
    Type "Can we afford dinner out this weekend?" → see the answer + "$814 safe to spend" → tap a transaction for detail.
  • What broke / looked fake
    (1) The API was stopped, so the question returned nothing. (2) "Safe to spend" felt high until the copy explained it was the whole remaining month. (3) A founder asked for a forecast nudge mid-walkthrough — a real feature gap, not a polish issue.

Outputs · fixes, one bounce, and learnings

Fixed inline

  • Restarted with npm run dev and confirmed all three endpoints respond.
  • Relabelled the big number clearly ("Safe to spend this week, after bills") so it reads right on stage.

Bounced back to /3-build

The forecast nudge ("you're trending over on dining out") was on the blueprint's Should list, not built yet. Since it changed what the app does — not just how it looks — this went back to /3-build rather than being patched here: the blueprint's Should item was promoted to Must for this demo, one short build session added it, then testing resumed from this same walkthrough.

Believability pass

  • Re-ran npm run seed after confirming the 20 transactions still read as one realistic couple-month.
  • Added a "Kora is thinking…" loading state so the first ask never looks frozen.

Shipped

Demoed from localhost for the live walkthrough; shared a temporary link via npx localtunnel --port 5173 so a friend could try it before Demo Night.

Learnings — feed the next /1-problem

  • Surprise: people asked vague questions ("are we okay?") — the answer needs a confident default, not just keyword matches.
  • Idea change: the forecast nudge turned out to be a stronger hook than the raw number — worth leading with next time.
  • Next smallest thing: let a partner add a transaction and watch the safe-to-spend number move live.

Kora is clickable, believable, and shareable. Ready for Demo Night.
