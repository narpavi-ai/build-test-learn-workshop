Route A — Build in Lovable (no-code)

3–4 prompts → a clickable FridgeChef

The hands-on route. Paste these into Lovable one at a time, free-tier friendly.

Inputs · what you told the AI

  • App name & tagline?
    FridgeChef — "Type what's in your fridge, get dinner."
  • Brand vibe & colour?
    Warm and friendly; a fresh green.
  • Anything about the look that matters?
    Big ingredient box up top; appetising recipe cards.

Outputs · the prompt script

Prompt 1 · Scaffold the screen
Build a single-page app called FridgeChef. Top: a heading "FridgeChef" with the tagline "Type what's in your fridge, get dinner." Below: a text input placeholder "eggs, cheese, spinach…" and a green "Find recipes" button. Under that, an empty responsive grid where recipe cards will go. Warm, friendly style, fresh green accent.

Should produce: the empty screen with input + button. If it breaks: re-prompt with "just the layout, no data yet."

Prompt 2 · Add believable fake data
Add 6 hard-coded recipes (no backend): Cheesy Scramble, Spinach & Feta Omelette, Garlic Fried Rice, Tomato Pasta, Veggie Quesadilla, Banana Oat Pancakes. Each has a title, cook time, an emoji, and a list of ingredients. Show them as cards in the grid. When I type ingredients and click Find recipes, filter to recipes that use any typed ingredient.

Should produce: typing "eggs, cheese" filters to matching cards. If it breaks: ask it to "log the filter and show all cards if the box is empty."

Prompt 3 · Detail view
When I click a recipe card, open a detail view showing the title, cook time, full ingredient list, and 4–5 numbered steps. Add a "← Back to results" button.

Should produce: click a card → full recipe → back. If it breaks: "use a simple modal instead of routing."

Prompt 4 · Polish
Polish FridgeChef: fresh-green primary colour, rounded cards with soft shadows, a friendly empty state ("Tell me what's in your fridge ↑"), and a loading state. Make it look finished.

Should produce: a demo-ready look. If it breaks: stop here — polish is optional; a working demo beats a pretty broken one.

Free tier is ~5 credits/day, so 3–4 prompts. Don't debug in circles — re-prompt clearly instead. Next: /6-test-iterate, then publish to a URL.
