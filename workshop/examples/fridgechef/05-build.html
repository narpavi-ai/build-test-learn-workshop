Files touched in the starter template

  • apps/api/src/db.js — table items → recipes (title, time, ingredients, steps).

  • apps/web/src/App.jsx + components — labels reworded ("Find recipes", "ingredients"), cards show cook time.

Round-trip verified

Type eggs, cheese at localhost:5173 → ranked recipe cards → tap one → full recipe. Real data from SQLite, not faked.
